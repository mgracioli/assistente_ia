Aplicação Next com integração IA via API Google Gemini 

A arquitetura inicial foi pensada para ser um monolito, já que se trata de um app simples construído com o intuito de aplicar os novos conceitos aprendidos. Com o escalar da aplicação, a separação entre front e back-end poderá, e será, feita.

Após implementação do sistema de chat com a API Google Gemini, foram implementadas duas ferramentas (getWeather, sendMail) para o modelo utilizar
